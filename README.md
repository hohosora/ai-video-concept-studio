# AI Video Concept Studio｜AI 影片創作構思工作室

把影片創作者在前期規劃的 Know-how，轉化為任何人都能使用的直覺式引導介面。

> 核心理念：**先釐清創作想法，再建立視覺與分鏡，最後才生成提示詞。**

## 產品目標

- **新手友善**：不要求使用者具備提示詞、攝影或剪輯知識。
- **引導思考**：不只是補齊提示詞，而是協助判斷故事要呈現什麼。
- **圖像參考**：以同一場景、不同畫風的圖片協助選擇視覺方向。
- **充分自主**：選擇題、自由填寫與 GPT 協作並存；保留使用者已確定的想法。
- **創作連續性**：支援分鏡片段、角色與風格沿用；可以反覆修正。

## 三個步驟

1. **創作構思與視覺規劃**：自由描述、問答、GPT 訪談指令、故事回填、六種視覺參考及分鏡提示詞。
2. **AI 影片生成**：選擇 [Google Flow](https://flow.google.com/) 或 [Kling AI](https://kling.ai/app/ai-video)，自行生成並下載片段。
3. **剪輯與輸出**：前往獨立的 [Motion Creator Studio](https://bkj888.github.io/motion-creator-studio/) 匯入並合成影片。

## 目前版本：v0.1（獨立專案起點）

此版以先前的導航介面 v3.0 為基礎，重新定義專案定位並作為 GitHub Pages 首頁。保留既有可操作功能。它是**前端靜態網頁**，可直接開啟 `index.html`，無需建置工具或後端。

### 已有功能

- 有想法／沒想法兩種入口；自由填寫與 GPT 故事訪談指令。
- 六題引導問答；選風格時有六張風格比較圖（內嵌於 HTML）。
- 英文／中文提示詞與多片段管理；第二段可沿用角色和畫風。
- 選擇 Google Flow 或 Kling，提供手動操作連結與指引。
- 直接銜接 Motion Creator Studio（跨站不自動轉移影片）。
- 暖灰米與柔和鼠尾草綠介面；主要資料儲存在本機瀏覽器。

### 尚未實作／限制

- GPT 對話需開啟 ChatGPT，**複製指令並將結果貼回**；目前沒有直接串接 OpenAI API。
- 不會代替使用者登入 Google Flow／Kling、執行生成或自動下載。
- 影片檔不會經本站跨站上傳到 Motion Creator Studio。
- 分鏡規劃以文字為主，尚無真正的分鏡圖生成或完整故事企劃匯出。
- 若需直接在頁面使用 GPT，必須設計後端來安全保管 API 金鑰，也可能產生費用。

## 後續開發方向

1. **創作企劃書**：故事主旨、受眾、情緒、人物設定、鏡頭序列與變更紀錄。
2. **適應式訪談**：偵測模糊資訊，只追問仍不清楚的重點；避免僵硬的固定題數。
3. **可視化分鏡**：依畫面參考建立分鏡卡，協助確認風格與角色一致性。
4. **平台化提示詞**：依不同生成模型給出合適格式、長度與運鏡建議。
5. **可靠的儲存與回復**：匯出／匯入創作計畫，避免只仰賴單一瀏覽器。

避免在此專案重複開發完整的影片剪輯器。

## GitHub Pages 部署

建立獨立儲存庫 `hohosora/ai-video-concept-studio` 後，將本資料夾的 `index.html`、`README.md` 上傳到儲存庫根目錄。進入 `Settings → Pages → Build and deployment`，設定 `Deploy from a branch`、`main`、`/(root)`，再按 `Save`。網站預計網址：

`https://hohosora.github.io/ai-video-concept-studio/`

**注意**：這是預計網址，只有在建立儲存庫並完成 Pages 發布後才能開啟。原有 `BKJ888/motion-creator-studio` 不需要更改。

## 公開程式碼注意事項

若儲存庫選擇 Public，網站程式碼及內建的引導規則都能被他人檢視。請不要把 API 金鑰、私人客戶資料、未公開的專有素材或其他秘密寫入網頁程式碼。
