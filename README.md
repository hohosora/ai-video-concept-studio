# AI Video Concept Studio v0.2 — 草案先行版

## 這版解決的問題
過去「已有方向」路徑會要求 ChatGPT 每輪問 2–4 個選項、最多五輪，貼回網站後又必須回答六題。這會讓自由構思模式與「完全沒想法」的問卷路徑沒有明確差異。

## 新流程
- **我有一些方向**：自由描述 → 複製 GPT 創作指令 → GPT 第一則回覆直接提出可編輯的故事＋鏡頭方案（最多一個真正關鍵問題，並非必答） → 貼回後只確認**圖片畫風**與**影片比例** → 產出影片片段提示詞。
- **我完全沒有想法**：維持六題的選擇式引導。
- 已有想法的提示詞以故事為最高優先，不再添加任意預設角色、場景、動作。
- 不變：Google Flow／Kling 引導、跳轉 Motion Creator Studio、影片片段管理、暖色介面。

## 使用與限制
本專案仍使用複製指令至 ChatGPT 的方式，**並未在網頁內直接串接 OpenAI API**。中文故事若未經 GPT 產生對應英文描述，英文字欄可能保留原始中文內容。第三方影片生成、下載和剪輯仍需使用者操作。

## 部署
將 `index.html` 放進獨立 GitHub 儲存庫根目錄，在 Settings → Pages 啟用 main 分支根目錄發布。**請勿覆蓋 BKJ888/motion-creator-studio 原專案**。
